# Map models (STORM DROP)

Photo-real environment assets for the island, generated by `tools/make_map.py` with Blender 4.5 LTS
(headless, Python API). Everything is original and procedural: geometry built with bmesh, PBR textures
(base colour up to 1024 px; roughness/metallic and normal at half that; JPEG) synthesised in numpy and
embedded in each `.glb`. The rock textures are baked from a high-poly sculpt with Cycles. No Draco compression.

## Conventions
* Metres, **+Y up**, door side faces **+Z**, origin = centre of the footprint at floor/ground level (y = 0).
* Buildings have two nodes: `*_structure` contains floor slab, walls and flat ceiling slab and matches the game's
  collider boxes exactly. `*_details` contains roofs, trim, windows, gutters, chimney and interior beams. The windows
  are visual only; the walls behind them are solid.
* Cottages: 8 × 8, floor slab 0–0.35, walls 0.35 thick up to y = 4.55, ceiling slab 4.55–4.85 (8.6 × 8.6, the same as
  `buildHouse` in `index.html`), doorway 1.8 × 2.6 centred on +Z and left open, door leaf swung inside against the
  front wall. The gable roof sits above the slab.
* Warehouse 28 × 18 (walls 0.6, 9 tall, roof slab 9.3–9.7 at 28.8 × 18.8), 7 × 5 openings on ±Z with the roller doors rolled up.
* Barn 12 × 10 (walls 0.4, 6 tall over a 0.3 floor, ceiling slab 6.3–6.6 at 12.6 × 10.6), 4.5 × 3.8 door on +Z, roof ridge along Z.
* Silo: radius 2.3, cylinder top at y = 11, dome to y ≈ 13.4. The ladder (+X) and fill pipe (−X) stand slightly outside the radius.
* `chest.glb`: root `Chest` (body 1.4 × 0.7 × 0.9) with child **`Lid`**. The lid's origin is the hinge on the back top edge
  (0, 0.7, −0.45); rotate it about its local X to open.
* `fence.glb`: 4 m section from x = −2 to +2, posts at x = −2 and 0. Place sections 4 m apart and the next section's post closes the joint.
* `container.glb` uses light-grey paint, so the game can tint it. `container_red/blue/green/orange.glb` are painted variants.
* Trees, the grass clump and the flower boxes on `house_c` use alpha-card leaves exported with `alphaMode: MASK` (double-sided).

## Regenerating
```bash
pip install bpy==4.5.16          # Python 3.11, or use a Blender 4.x install
python tools/make_map.py         # all assets + verification + renders
python tools/make_map.py --only house_a,barn --no-render
blender -b -P tools/make_map.py -- --render-only --quick
```
