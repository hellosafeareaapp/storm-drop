# STORM DROP

A cartoony third-person battle royale that runs in your browser. It's a single HTML file built with Three.js, and every model is made in code.

You and 15 AI bots drop from an airship onto an island. Loot weapons, build cover, outlast the storm, and be the **last one standing**.

## Play
Open `index.html` in a desktop browser (Chrome, Edge or Firefox). No install needed.

## Controls
| Key | Action |
|---|---|
| Mouse | Look / aim |
| WASD | Move |
| Space | Jump / drop from the airship |
| Shift | Sprint |
| Ctrl / C | Crouch |
| Left click | Shoot / swing / build / heal |
| Right click | Aim down sights (sniper scope) |
| 1–5 | Inventory slots (build pieces in build mode) |
| F | Pickaxe (hit trees for wood) |
| E | Open chests / pick up loot |
| R | Reload |
| Q | Toggle build mode |

## Features
- Airship drop-in, skydive and auto-glider
- 5 weapons (AR, shotgun, SMG, sniper, rocket launcher) in 5 rarities
- Chests, floor loot, ammo, bandages, med kits, shield potions
- Building: walls, floors, ramps and roofs, made from wood you harvest
- A storm that shrinks in stages, plus a minimap
- 15 bots that loot, fight, strafe, take cover and avoid the storm
- All sound effects synthesized with the Web Audio API

## Gun models
Realistic-looking gun models live in `models/guns/` (glTF binary, ready for Three.js `GLTFLoader`):

| File | Triangles | Size | Length |
|---|---|---|---|
| `models/guns/ar.glb` | 5,172 | 574 KB | 0.93 m |
| `models/guns/shotgun.glb` | 3,844 | 465 KB | 1.02 m |
| `models/guns/smg.glb` | 3,340 | 420 KB | 0.60 m |
| `models/guns/sniper.glb` | 4,542 | 523 KB | 1.21 m |
| `models/guns/rocket.glb` | 4,710 | 481 KB | 1.18 m |

All five are original, generic designs, generated by the Blender script `tools/make_guns.py`. Previews are in `models/guns/previews/`, and `models/guns/stats.json` holds the numbers above.

- Units are metres at real scale. +Y is up, the barrel points along +Z, and the origin is at the pistol grip.
- Each model has an empty node named `Muzzle` at the barrel tip.
- The material named `Accent` is a small stripe or panel. The game can recolour it per rarity.
- The other materials are PBR (`Gunmetal`, `Polymer`, `Walnut`, `OliveDrab`, `Lens`). Edge wear, scratches, wood grain and bevelled-edge normals are baked into embedded JPEG textures. There is no Draco compression.

To regenerate (Blender 4.2, or `pip install bpy==4.2.0` on Python 3.11):
```bash
blender -b -P tools/make_guns.py -- ar shotgun smg sniper rocket
```
```bash
python tools/make_guns.py ar shotgun smg sniper rocket
```
The script builds each gun, bakes its textures in Cycles, exports the `.glb`, then re-imports it to check for the `Muzzle` empty and the `Accent` material, and renders the preview.
